the safety model

Nothing flushes
without asking.

safe

A cache the tool rebuilds or re-downloads on demand.

caution

Re-downloading is slow or large, or it removes old versions.

danger

Can lose data. Needs yes typed in full, is never in a preset, and is refused by --yes.

  • Scan, choose, confirm, clean, report. Nothing is removed before you confirm.
  • --list and --dry-run change nothing at all.
  • Never deletes outside your home folder, and refuses to run as root.
  • Agent settings, credentials and memory are never touched. Session transcripts are danger items.
  • Editor caches are skipped while the editor is open.
  • Every cleaning run writes a log, so you can see exactly what went.

install

Install the cleaner.

No sudo, no root, no package manager required. bash 3.2 or newer, so the stock macOS bash is fine.

Homebrew

brew install bankerneel/tap/cleancodeshit

Manual install

sheet 1 of 3

Download the release

u=https://github.com/bankerneel/cleancodeshit/releases/download/v1.2.1
curl -fsSL -O "$u/cleancodeshit"      -O "$u/cleancodeshit.sha256"      -O "$u/install.sh"
Three files, one folder.

sheet 2 of 3

Check the checksum

shasum -a 256 -c cleancodeshit.sha256   # macOS
sha256sum -c cleancodeshit.sha256       # Linux
Both print cleancodeshit: OK.

sheet 3 of 3

Install, then look first

bash install.sh
cleancodeshit --dry-run
Installs to ~/.local/bin.
